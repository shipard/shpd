# Install hardening + nástroje pro náhledy (D1–D5)

**Status:** implementováno (commity 0141b44, 0c41163, 259d5fb) — zbývá manuální verifikace idempotence na čistém prostředí
**Vzniklo z:** debugging na ns-alpha — PDF náhledy se tiše negenerovaly (chybějící binárky), opakované spuštění `install-packages.sh` přepsalo nginx konfiguraci

---

## Cíl

1. `scripts/install-packages.sh` instaluje nástroje pro generování náhledů (dosud je instaloval jen `docs/attachments.md` §9 „na papíře").
2. `shpd-server doctor` odhalí chybějící binárky — přesně tento případ dnes projde bez povšimnutí.
3. `ThumbnailGenerator` při selhání CLI nástroje zanechá stopu v logu (dnes: stderr do `/dev/null`, tichý fallback na generickou ikonu).
4. `install-packages.sh` je skutečně idempotentní — nepřepisuje server-owned nginx site file.

## Návaznost

- `docs/attachments.md` §5 (nástroje), §9 (systémové závislosti)
- `scripts/install-packages.sh` — sekce 4 (apt), sekce 8 (nginx site)
- `src/Command/Server/DoctorCommand.php` + `tests/Unit/Command/Server/DoctorCommandTest.php`
- `modules/core/attachments/src/ThumbnailGenerator.php` + `tests/Unit/Module/Core/Attachments/ThumbnailGeneratorTest.php`
- `src/Core/Logging/ErrorLogger.php` — statický logger (`warn(string $msg, array $ctx = [])`)

## Rozhodnutí

- **D1:** Do hlavního `apt-get install` v `install-packages.sh` přidat `poppler-utils librsvg2-bin libvips-tools`.
- **D2:** `DoctorCommand` dostane sekci „Thumbnail tools" — kontrola přítomnosti binárek `pdftocairo`, `rsvg-convert`, `vipsthumbnail`, `vips` v PATH. Chybějící binárka = error (✗), přispívá do `$totalIssues` a exit code, s hintem na konkrétní apt balíček.
- **D3:** `ThumbnailGenerator` nezahazuje stderr — zachytí výstup (`2>&1`), při nenulovém exit code zaloguje `ErrorLogger::warn` s nástrojem, exit code a posledními řádky výstupu. Exit 127 má specifickou hlášku „nástroj není nainstalován" + apt hint. Tichá degradace na generickou ikonu v API zůstává (selhání náhledu není fatální).
- **D4:** Generování nginx site file je idempotentní: pokud `/etc/nginx/sites-available/shipard.conf` existuje, přeskočí se (hláška + hint na `--force-nginx`). Nový přepínač `--force-nginx` vynutí přegenerování. Generovaný soubor dostane hlavičkový komentář (kdy/čím vygenerován, že skript ho už nepřepíše, že verzované parametry žijí v includech). Symlink v `sites-enabled` a deaktivace konfliktních sites zůstávají beze změny (už jsou idempotentní).
- **D5:** FPM pool file (`pool.d/shipard.conf`) se **záměrně** přegenerovává při každém běhu — je plně odvozený (user, socket, include path), manuální edity se nepředpokládají. Known behavior: po upgradu PHP verze se změní socket v pool file, ale ne v (nepřepisovaném) site file — nesoulad hlásí `doctor` (`checkFpmSocket`/`checkNginxRouting`). Zdokumentovat komentářem ve skriptu.

**Sekce 4 (apt):** do hlavního instalačního příkazu přidat balíčky pro náhledy:

```bash
apt-get install -y \

    poppler-utils librsvg2-bin libvips-tools \

```

**Sekce 7 (FPM pool):** nad generování pool file přidat komentář (D5):

```bash
# NOTE (D5): the pool file is fully derived (user, socket, include path) and is
# intentionally REGENERATED on every run. Manual edits do not belong here —
# versioned parameters live in docs/php/shipard-fpm-common.conf. A PHP version
# upgrade changes the socket here but not in the (server-owned) nginx site
# file — that mismatch is reported by `shpd-server doctor`.
```

**Sekce 8 (nginx site):** generování obalit podmínkou; hlavička do generovaného souboru:

```bash
if [ -f "$SITE_FILE" ] && [ "$FORCE_NGINX" != "1" ]; then
    echo "==> nginx site exists: $SITE_FILE — leaving as-is."
    echo "    (Server-owned file. Regenerate explicitly with --force-nginx.)"
else
    echo "==> Installing nginx site: $SITE_FILE"
    {
        echo "# Generated by install-packages.sh on $(date -Iseconds) from docs/nginx/${MODE}.conf"
        echo "# Server-owned file: re-running install-packages.sh will NOT overwrite it."
        echo "# Regenerate explicitly: sudo bash scripts/install-packages.sh --mode=${MODE} --force-nginx"
        echo "# Versioned parameters live in docs/nginx/shipard-*.conf includes (git pull + reload)."
        sed "s|fastcgi_pass unix:/run/php/[^;]*;|fastcgi_pass unix:${POOL_SOCKET};|g" "$TEMPLATE"
    } > "$SITE_FILE"
    chmod 0644 "$SITE_FILE"
fi

ln -sfn "$SITE_FILE" "$SITE_LINK"   # beze změny — vždy
```

Deaktivace konfliktních sites (`for stale in ...`) beze změny. `nginx -t` + reload beze změny (běží i při přeskočení generování — neškodí).

### 2. `src/Command/Server/DoctorCommand.php`

Nová sekce výstupu mezi „System config includes" a „Data source DB connections":

```
<info>Thumbnail tools</info>
  ✓ pdftocairo (/usr/bin/pdftocairo)
  ✗ vipsthumbnail: not found in PATH
    → Install: sudo apt install libvips-tools
```

**Nové metody:**

```php
/** Mapa binárka → apt balíček (hint pro admina). */
private const THUMBNAIL_TOOLS = [
    'pdftocairo'    => 'poppler-utils',
    'rsvg-convert'  => 'librsvg2-bin',
    'vipsthumbnail' => 'libvips-tools',
    'vips'          => 'libvips-tools',
];

/**
 * Finds a binary in PATH. Pure-PHP scan (no exec) — deterministic and
 * overridable in tests.
 */
protected function findBinary(string $name): ?string
{
    $path = getenv('PATH') ?: '/usr/local/bin:/usr/bin:/bin';
    foreach (explode(':', $path) as $dir) {
        if ($dir === '') { continue; }
        $candidate = $dir . '/' . $name;
        if (is_file($candidate) && is_executable($candidate)) {
            return $candidate;
        }
    }
    return null;
}

/** @return int number of missing thumbnail tools */
protected function checkThumbnailTools(OutputInterface $output): int
```

`checkThumbnailTools()` iteruje `THUMBNAIL_TOOLS`, přes `findBinary()` hlásí ✓ s cestou / ✗ s apt hintem, vrací počet chybějících. V `execute()` přičíst návratovou hodnotu do `$totalIssues`.

Severita: **error** (✗, ovlivňuje exit code) — nástroje jsou deklarovaná systémová závislost (`docs/attachments.md` §9) a jejich absence znamená tichou funkční degradaci; přesně tohle má doctor chytat.

### 3. `modules/core/attachments/src/ThumbnailGenerator.php`

**Nový centrální helper** — všechna tři volání `exec()` jdou přes něj:

```php
/**
 * Runs a CLI tool, captures stdout+stderr, logs a warning on failure.
 * Exit code 127 (command not found) gets a specific message with apt hint.
 */
protected function runTool(string $cmd, string $tool, string $aptPackage): bool
{
    exec($cmd . ' 2>&1', $output, $exitCode);
    if ($exitCode === 0) {
        return true;
    }
    $ctx = [
        'tool'     => $tool,
        'exitCode' => $exitCode,
        'output'   => implode("\n", array_slice($output, -5)),
    ];
    if ($exitCode === 127) {
        ErrorLogger::warn("thumbnail: tool '{$tool}' is not installed — sudo apt install {$aptPackage}", $ctx);
    } else {
        ErrorLogger::warn("thumbnail: tool '{$tool}' failed", $ctx);
    }
    return false;
}
```

**Úpravy metod:**
- `generatePdf()` — z příkazu odstranit ` 2>/dev/null`, volat `$this->runTool($cmd, 'pdftocairo', 'poppler-utils')`; navazující logika (glob, rename, cleanup) beze změny.
- `generateSvg()` — oba kroky přes `runTool()` (`rsvg-convert`/`librsvg2-bin`, `vips`/`libvips-tools`).
- `generateImage()` — přes `runTool()` (`vipsthumbnail`/`libvips-tools`).

**Testovací seam:** názvy binárek vytáhnout do protected properties, sprintf je používá:

```php
protected string $pdftocairoBin    = 'pdftocairo';
protected string $rsvgConvertBin   = 'rsvg-convert';
protected string $vipsBin          = 'vips';
protected string $vipsthumbnailBin = 'vipsthumbnail';
```

Import: `use Shipard\Core\Logging\ErrorLogger;`
