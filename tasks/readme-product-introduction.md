# README — představení aplikace
**Stav:** hotovo

## Cíl a návaznost

Představit aplikaci samostatným účetním s několika klienty a podnikatelům
spolupracujícím s vlastní účetní. Komunikační podpora M5 (veřejná beta)
z roadmapy; nejde o změnu funkcí ani pořadí implementačních milníků.

## Rozhodnutí

- Hlavní ukázka: přijatá faktura → kontrola návrhu → vystavený doklad.
- AI pomáhá s přípravou; člověk kontroluje správnost účetnictví.
- Spisovna není hlavním prezentačním tématem, dále se dopracovává.
- Dva skutečné screenshoty z ukázkových dat dodala uživatelka: kontrola
  návrhu z Dashboardu a stejná faktura po vystavení v přehledu.
- Technologie a odkazy pro vývojáře patří na konec.
